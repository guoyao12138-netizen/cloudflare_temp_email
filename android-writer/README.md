# 墨蓝写作 (InkBlue Writer)

一款安卓端网文创作 App。交互模仿「纯纯写作」的极简沉浸式写作体验，视觉模仿
Claude 的 UI 风格（衬线标题、奶白底色、圆角卡片、细边框、大留白），并将
Claude 标志性的珊瑚橙强调色替换为墨蓝色系。

## 功能

- **书架**：作品（书）管理——新建、编辑书名/简介、删除；展示章节数、总字数、最近更新时间
- **章节**：每部作品下的章节列表——新建（自动编号「第 N 章」）、重命名、删除
- **世界观构筑**：每部作品独立的设定库，按 人物 / 地点 / 物品 / 势力 / 设定 五类管理；分类筛选、卡片预览、独立编辑页（同样自动保存）；从章节页顶栏的地球图标或作品菜单进入
- **大纲规划**（章节页顶栏列表图标，v0.6.0）：剧情阶段卡片式大纲，可增删改、上下调序；「AI 规划大纲」基于世界观与已有大纲一键排布 5/10/15 个阶段（已有大纲时自动续排）；编辑器续写自动携带大纲，使 AI 知道当前进度与下一阶段走向
- **文风 Agent 与小说仿写**（书架页画笔图标 → 文风库，v0.6.0）：粘贴或导入 TXT 小说文本（UTF-8/GBK 自动识别），文风分析 Agent 研读并提炼七维「文风指南」（叙事视角、句式节奏、用词、对话、描写、基调、标志性技巧，每项附原文例证）存入文风库；编辑器新增「文风仿写」——选择文风档案后，无选区按该文风续写、有选区把选中文字改写为该文风
- **多 AI 服务与协作**（v0.5.0）：
  - 可添加多个 AI 服务（Anthropic 协议 / OpenAI 兼容协议），Base URL 支持官方地址、中转站、API 代理
  - **AI 分工**：指定「主笔模型」负责创作；可选「审校模型」开启多 AI 协作——世界观生成由主笔起草、审校模型对照已有设定复核定稿（审校失败自动回退草稿）
- **AI 修订**（设定编辑页 ✨ 按钮，v0.5.0）：对单条设定执行 扩写完善 / 精简凝练 / 一致性校对（对照全书设定纠矛盾）/ 自定义指令修订，结果预览后替换
- **AI 一键构筑世界观**（世界观页顶栏 ✨ 按钮，v0.3.0 起，v0.5.0 细化为 8 个模块）：
  - **模块化生成**：世界观框架、修炼体系、地区（城池/宗门驻地/秘境/王朝国度/荒野绝地）、势力（宗门/王朝/世家/魔道组织/商会）、单个角色（主角/反派/导师/挚友/配角）、物品法宝（武器/丹药/功法/天材地宝）、新手村、出场角色批量生成——每个模块都基于已有设定独立生成
  - **世界观框架**：选择世界类型（东方玄幻/仙侠/西幻/都市异能/科幻/末世/历史架空/悬疑灵异）+ 作者补充想法，一键生成 5–8 条互相自洽的设定（总纲、地域、势力、规则）
  - **修炼体系**：设定「境界表现力」（内敛写实 / 热血张扬 / 毁天灭地），生成境界划分、能力表现、突破方式与配套功法资源
  - **新手村**：基于已有世界观生成主角开局之地，含风土人情、势力关系、机缘与危机
  - **出场角色**：生成 3/5/7 个开篇角色，每个含性格、外貌、背景来历与关系定位，命名风格统一贴合世界观
  - 所有生成都携带作品已有设定作为上下文，保证前后自洽；结果先预览，可重试，「全部保存」批量入库
- **创作助手 Agent**（章节页底部「助手」，v0.7.0）：按作品的多轮对话智能体，自动携带全书世界观、大纲、章节列表与最新章节结尾；可讨论剧情、产出正文片段、改稿、起名；支持联网搜索开关
- **写作技能 Skill**（v0.7.0）：可在 AI 写作面板选用的技法指令包，内置 黄金三章/爽点节奏/感官沉浸/对话推动/悬念钩子 五个预设，设置页可增删改自定义技能
- **联网搜索**（v0.7.0）：AI 写作与创作助手可开启 Claude 服务端 `web_search` 工具（仅 Anthropic 协议），先查资料再写作
- **AI 辅助写作**（编辑器底部符号栏 ✨ AI）：
  - **续写**：自动携带书名、简介与全部世界观设定作为上下文，续写约 300 字，可一键插入正文
  - **润色**：润色选中的文字，一键替换
  - **情节灵感**：基于当前章节结尾给出 3 个后续走向建议
  - AI 插入/替换均进入撤销栈，可随时撤销
  - 需自备 API Key（仅存本机）；支持 **Claude（Anthropic 官方 Messages API，默认 `claude-opus-4-8`）** 与 **OpenAI 兼容协议**（DeepSeek / Kimi / OpenRouter 等，默认 DeepSeek），可自定义 Base URL 与模型名
- **沉浸式编辑器**（模仿纯纯写作核心体验）：
  - 无干扰全屏写作，仅保留一条极简顶栏（返回 / 实时字数 / 保存状态 / 撤销 / 重做）
  - **自动保存**：停笔 600ms 自动入库，退出编辑器时强制保存，永不丢稿
  - **撤销 / 重做**：按 1 秒输入窗口分组的快照式历史，最多 200 步
  - **回车自动缩进**：换行后自动插入两个全角空格（可在设置中关闭）
  - **中文符号快捷栏**：「」『』""（）——……，。？！：；、一键插入，成对符号自动将光标置于中间
  - 字数统计采用纯纯写作风格：所有非空白字符均计入
- **屏幕适应**（v0.4.0）：书架/章节/世界观列表在平板与横屏下自适应多列网格；编辑器正文限宽 760dp 居中保持可读行宽；旋转屏幕不重建界面、编辑状态无损
- **帧数**（v0.4.0）：「高刷新率」开关（按设备最高刷新率运行，90/120Hz 生效）；「帧率显示」开关（右上角实时 FPS）
- **设置**：浅色 / 深色 / 跟随系统主题，正文字号（14–26sp，带实时预览），自动缩进开关
- **macOS Intel 桌面版**（v0.6.1，`desktop/` 目录）：Compose Desktop 实现，与安卓同源的蓝色 UI 与功能（书架/章节/大纲/世界观/文风库/AI 写作/多 AI 协作），数据存于 `~/.inkblue-writer/data.json`；Release 附带 `*-mac-intel.dmg`（未签名，首次打开需右键 → 打开）
- **深色模式**：蓝调炭黑夜间主题

## 技术栈

- Kotlin + Jetpack Compose (Material 3)，单 module
- Room (SQLite) 持久化作品与章节
- DataStore Preferences 持久化设置
- Navigation Compose 导航：书架 → 章节 → 编辑器 / 世界观
- 网络仅用于可选的 AI 写作（直连你配置的 API 服务商）；作品数据与 API Key 全部仅存本地

## 构建

需要 Android Studio（或本机已安装 Android SDK，compileSdk 35）与 JDK 17：

```bash
cd android-writer
./gradlew :app:assembleDebug
# APK 输出: app/build/outputs/apk/debug/app-debug.apk
```

或直接用 Android Studio 打开 `android-writer/` 目录运行。

> 注意：构建需要访问 Google Maven (`dl.google.com`) 下载 Android Gradle Plugin。

### 签名说明

自 v0.4.0 起，所有构建（本地与 CI）统一使用仓库内的固定密钥 `inkblue.keystore` 签名，
版本之间可直接覆盖安装升级。该密钥仅用于侧载分发的签名一致性，不是商店发布密钥。

**从 v0.3.0 或更早版本升级**：旧版本由 CI 临时密钥签名，签名不一致，需先卸载旧版再安装
（卸载会清除本地数据，请先在世界观/章节中长按导出或抄录重要内容）；此后所有版本均可直接覆盖升级。

## 设计说明（Claude UI → 蓝色化）

| Claude 原版 | 本应用 |
|-------------|--------|
| 珊瑚橙强调色 `#D97757` | 墨蓝 `#4A6FE3`（深色模式 `#8CA8F5`） |
| 暖米白背景 | 冷调云白 `#F6F8FC` |
| 衬线标题字体 | 系统衬线 (Noto Serif) 用于标题/书名/章节名 |
| 白色圆角卡片 + 细边框 | 同款：16dp 圆角、1dp 发丝边框、无阴影 |
| 炭黑深色模式 | 蓝调炭黑 `#1B1E26` |
